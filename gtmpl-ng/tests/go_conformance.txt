#
#   {{ printf "%s" 18446744073709551615 }}

#
#   {{ printf "%d" .Missing }} and {{ printf "%s" .Missing }}
#       Rendered with nil data, Go treats a field of an invalid value as absent and
#       prints `%!d(<nil>)`. This engine reports that nil has no fields. See the
#       nil-root-context finding.
#
#   {{ printf "%5c" 5 }}
#       Identical output; only the debug quoting differs, since Rust writes a control
#       character as `\u{5}` where Go writes `\x05`. Verified byte for byte.
